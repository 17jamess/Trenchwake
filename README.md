# Trenchwake: World Conquest

**Hold the front. Keep it supplied.** An unofficial Roblox territory strategy adaptation of OpenFront, with a 2,000 × 1,000 world, forward bases, persistent rail infrastructure and solo AI campaigns.

## Complete editable source

[Download Trenchwake-Source.zip](./Trenchwake-Source.zip) for the complete preferred source, licensed assets, notices, QA, build scripts and documentation for this release. The archive is **12,228,288 bytes**. SHA-256:

`42adeee25f66f1def83c38f5b28c1de2d8f6349fae955a47e437d800e501d87b`

Extract it into a new folder and run `./rebuild-place.ps1` in PowerShell. The generated `Trenchwake.rbxlx` can be opened in Roblox Studio. Enable Mesh / Image APIs for terrain and artwork, as explained in the archive's README.

The [Roblox experience](https://www.roblox.com/games/123209925514168) also offers an editable copy through its menu's **Edit in Studio** option. Its `ServerStorage.SourceDistribution` folder contains the same full source archive and extraction instructions; the running Luau is immediately editable. Public play availability and Roblox's review/account eligibility are separate from source availability.
